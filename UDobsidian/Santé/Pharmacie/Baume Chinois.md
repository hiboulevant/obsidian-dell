# Baume Chinois
Soulage les articulations douleureuses.

Le baume chinois est un remède naturel et ancestral dont les multiples propriétés sont connues pour **soigner les maux du quotidien, lutter contre les douleurs musculaires et articulaires, apaiser les migraines, dégager les voies respiratoires, soulager les piqûres d'insectes**…
