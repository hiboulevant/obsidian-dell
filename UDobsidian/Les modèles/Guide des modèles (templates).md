# Guide des modèles (templates)

### Bienvenue dans le guide des templates pour Obsidian ! Obsidian est un outil de prise de notes basé sur Markdown qui vous permet de créer et d'organiser des documents interconnectés. Les templates sont des modèles prédéfinis que vous pouvez utiliser comme point de départ pour créer différents types de notes et de structures dans Obsidian. Voici quelques exemples de templates populaires que vous pouvez utiliser dans Obsidian :

1. ####**Journal quotidien** : Un modèle de journal qui vous permet d'enregistrer vos réflexions quotidiennes. Incluez des sections pour la date, les objectifs, les tâches, les événements importants et les notes personnelles.

2. **Suivi de projet** : Un modèle pour suivre les détails d'un projet spécifique. Incluez des sections pour les objectifs du projet, les étapes clés, les tâches à accomplir, les échéances et les ressources pertinentes.

3. **GTD (Getting Things Done)** : Un modèle basé sur la méthode de productivité GTD de David Allen. Incluez des sections pour les tâches à faire, les tâches en attente, les tâches planifiées et les tâches terminées.

4. **Fiche de livre** : Un modèle pour prendre des notes sur les livres que vous lisez. Incluez des sections pour les informations sur l'auteur, un résumé du livre, les points clés, les citations intéressantes et vos réflexions personnelles.

5. **Planification d'événement** : Un modèle pour organiser et planifier un événement. Incluez des sections pour la date, l'objectif de l'événement, la liste des invités, les tâches à accomplir, les besoins matériels et toute autre information pertinente.

6. **Mind mapping** : Utilisez Obsidian pour créer des mind maps. Commencez par une note centrale représentant le sujet principal, puis ajoutez des sous-notes pour explorer et organiser les idées connexes.

7. **Journal de gratitude** : Un modèle pour enregistrer quotidiennement ce pour quoi vous êtes reconnaissant. Incluez des sections pour les moments positifs de la journée, les personnes qui vous ont aidé et les petites victoires.

Pour utiliser ces templates dans Obsidian, vous pouvez les créer manuellement en ajoutant les sections et les balises Markdown correspondantes, ou vous pouvez rechercher des plugins Obsidian spécifiques qui offrent des fonctionnalités de template.

L'utilisation de templates dans Obsidian peut vous aider à gagner du temps et à maintenir une structure cohérente dans vos notes. N'hésitez pas à personnaliser ces modèles en fonction de vos besoins spécifiques et à explorer d'autres idées de templates en fonction de votre utilisation d'Obsidian.
