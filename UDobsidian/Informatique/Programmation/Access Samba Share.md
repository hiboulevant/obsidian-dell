## Étape 6: Access Samba Share à partir de Windows
#Samba #hostname #ipadress 
Ici, remplacez "hostname-or-ip-address" par le nom d'hôte ou l'adresse IP réel de votre système Linux.

Saisissez les identifiants de l'utilisateur Samba lorsqu'on vous y intéresse et appuyez sur Entrée. Vous pouvez maintenant parcourir, lire, écrire ou supprimer des fichiers dans le dossier partagé.

Conclusion

Dans ce tutoriel, nous avons expliqué comment installer et configurer Samba sur Linux Mint. Avec Samba installé, vous pouvez facilement partager des fichiers entre les systèmes Linux et Windows.

Si vous voulez vous auto-héberger d'une manière facile, mains libres, avez besoin d'une adresse IP externe, ou si vous voulez simplement vos données en main, essayez [IPv6.rs](https://ipv6.rs).
