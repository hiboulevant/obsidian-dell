# Les commandes terminaux
ls ou dir: liste simple et épurée
ls -la  [^1] : liste horizontal détaillé y compris les fichiers cachés. Ou liste en vue. On peut aussi utilisé: dir -la
pwd[^3] : dans quel dossier on trouve [^2]
Cd : change directory[^4]
Cd .. Il me replace vers home
Cd ../.. Il remonte de deux dossiers
Cd ~ : permet de remonter à mon dossier utilisateur
Clear : nettoyer son terminal https://www.docstring.fr/formations/le-terminal/la-commande-clear-39/?module=3&session=3&course=1


[^1]: Le tiret est un flag ou paramètre

[^2]: Le tilde ~ prend place du chemin du dossieur ou vous vous situer.
[^3]: print writting directory, si rien on trouve le ~
[^4]: pour indiquer le cd je puis faire copier - coller ou bien:  tapper les premières lettres et appyer tab pour compléter.

Clear: nettoyer mon terminal
mkdir: créer un dossier
mkdir../ : créer un dossier au supérieur
rm -r : supprimer un dossier
rm : sans flag on supprime un fichier
touch : permet de créer un fichier
