### Importer des modules = ## par exemples : import random
----- 
En Python 3, ==il n'y a pas de "fonctions" réservées au sens strict de mots-clés, mais plutôt des **fonctions intégrées** ([built-in functions](https://www.google.com/search?sca_esv=2dd93a768402da25&sxsrf=ANbL-n4bTPuSubagd7xWS-MeQtqkBORViA%3A1769642922278&q=built-in+functions&spell=1&sa=X&ved=2ahUKEwiQl6nSsa-SAxXAGFkFHZAaEpUQgK4QegQIARAC&biw=1920&bih=927&dpr=1&aic=0)) et des **[mots-clés réservés](https://www.google.com/search?sca_esv=2dd93a768402da25&sxsrf=ANbL-n4bTPuSubagd7xWS-MeQtqkBORViA%3A1769642922278&q=mots-cl%C3%A9s+r%C3%A9serv%C3%A9s&spell=1&sa=X&ved=2ahUKEwiQl6nSsa-SAxXAGFkFHZAaEpUQgK4QegQIARAD&biw=1920&bih=927&dpr=1&aic=0)** qui structurent le langage==. Les fonctions intégrées principales incluent `print()`, `len()`, `input()`, `type()`, `int()`, `float()`, `str()`, `list()`, `range()`, et `sum()`
