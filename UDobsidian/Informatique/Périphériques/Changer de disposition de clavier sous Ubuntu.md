# Changer de disposition de clavier sous Ubuntu



Oui, c'est tout à fait possible et courant dans Ubuntu (y compris la version 24.04 LTS). Le changement de disposition de clavier avec des touches ou raccourcis clavier est une fonctionnalité standard.

Voici comment le configurer dans **Ubuntu 24.04 LTS** (qui utilise l'environnement GNOME par défaut) :

### 1. Ajouter vos dispositions de clavier
*   Allez dans **Paramètres** (roue dentée) → **Clavier** → **Gestion des langues et de la saisie** (ou directement "Dispositions de clavier" dans certains menus).
*   Sous **Dispositions de clavier**, cliquez sur le bouton **+** (Ajouter une disposition).
*   Choisissez la ou les langues/dispositions que vous souhaitez (par exemple, **Français**, **Anglais (US)**, **Arabe**, etc.).
*   Validez.

### 2. Configurer le raccourci de bascule (comme sous Fedora/GNOME)
*   Toujours dans **Paramètres** → **Clavier**.
*   Faites défiler jusqu'à la section **Raccourcis spéciaux** (ou "Raccourcis personnalisés" dans certaines versions).
*   Cherchez la catégorie intitulée **Saisie** ou **Disposition de clavier**.
*   Vous devriez y voir l'option **Passer à la source de saisie suivante**. Cliquez dessus et appuyez sur le raccourci clavier de votre choix.
*   **Le raccourci le plus courant (et celui par défaut sous Fedora/Windows)** est **Alt + Shift**. Vous pouvez également utiliser **Super (Win) + Espace** (celui par défaut dans beaucoup de configurations GNOME).

### 3. Autre méthode : Paramètres régionaux et langues
*   Vous pouvez aussi passer par **Paramètres** → **Général** → **Langue et Région**.
*   Dans la section **Format**, cliquez sur le bouton **...** à côté de "Langues de saisie" pour gérer les dispositions et les raccourcis.

### Points importants :
*   **Indicateur dans la barre de menu** : Une fois configuré, un indicateur (comme **FR**, **EN**, **AR**) apparaît généralement dans la barre de menu en haut à droite. Vous pouvez cliquer dessus pour changer manuellement ou voir la disposition active.
*   **Ordre de bascule** : Le raccourci parcourt les dispositions dans l'ordre où elles sont listées dans les paramètres. Vous pouvez les réorganiser par glisser-déposer.
*   **Raccourci par défaut d'Ubuntu 24.04** : Par défaut, Ubuntu utilise souvent **Super (Win) + Espace**. Si vous préférez **Alt + Shift** (plus proche de Fedora/Windows), vous devez le définir manuellement comme expliqué ci-dessus.

**En résumé : Oui, le comportement est identique à Fedora 43** (puisque les deux utilisent l'environnement de bureau GNOME). La configuration se fait au même endroit et avec les mêmes options. Vous pouvez facilement définir **Alt + Shift** ou tout autre raccourci pour basculer entre vos langues.
