# Coller une image
#image #coller/image #obsidian 

Peux--t-on coller une image dans une page Obsidian.

Oui, vous pouvez coller une image directement dans une page Obsidian ! Voici comment procéder :

---

### **Méthode 1 : Coller via le presse-papiers (Ctrl/Cmd + V)**
1. **Copiez une image** (depuis un site web, un screenshot, etc.) ou utilisez **Ctrl+C/Cmd+C**.
2. Dans Obsidian, placez votre curseur où vous voulez insérer l'image.
3. **Collez** avec **Ctrl+V/Cmd+V**.
   - Obsidian va **enregistrer automatiquement l'image** dans votre vault (dossier de stockage) et générer le code Markdown correspondant :  
     `![[nom_image.png]]`.

---

### **Configuration recommandée (Paramètres d'Obsidian)**
Pour organiser vos images :
1. Allez dans **Paramètres** (Ctrl/Cmd + ,).
2. Sous **Fichiers et liens** → **Emplacement des nouveaux fichiers joints**, choisissez un dossier (ex : `Attachments`).
   - Cela évite d'éparpiller les images à la racine du vault.

---

### **Autres méthodes**
- **Glisser-déposer** : Déposez directement un fichier image depuis votre explorateur de fichiers dans Obsidian.
- **Syntaxe Markdown manuelle** : Utilisez `![Texte alternatif](lien/vers/image.png)` pour insérer une image existante.

---

### **Remarques**
- Les images ne sont pas intégrées *dans* le fichier .md, mais **liées** en tant que fichiers séparés. Gardez-les dans votre vault !
- Si le collage ne fonctionne pas, vérifiez vos paramètres de dossier d'attachements ou les permissions d'accès.

Avec ça, vos notes seront plus visuelles ! 🖼️
