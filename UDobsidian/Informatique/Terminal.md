# Terminal

Basculer rapidement entre les deux dernier dossiers.

Pour basculer instantanément entre vos deux derniers dossiers, utilisez un simple trait d'union.

La commande est la suivante :

`cd -`

💡 Points clés à retenir :

- **Action** : Cette commande vous ramène exactement là où vous étiez juste avant.
- **Raccourci** : Elle agit comme le bouton "Retour" de votre téléviseur.
- **Affichage** : Le terminal affiche automatiquement le chemin du dossier où vous venez d'atterrir.

Si vous étiez dans `/mnt/c/merlin/bon/matin` et que vous venez d'aller dans `/etc`, tapez `cd -` pour revenir à `/matin`. Tapez `cd -` une nouvelle fois pour retourner dans `/etc`.
