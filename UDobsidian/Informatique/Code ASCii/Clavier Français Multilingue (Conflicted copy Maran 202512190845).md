# Clavier Français Multilingue

Clavier Lenovo sur Windows 11 

`  : alt Dr + ( + barre d'espacement    

~ : alt Dr + ) + + barre espacement  

°  : alt Dr + : 

<  : alt Dr + , 

>  : alt Dr + . 

[  : alt Dr + 9  

]  : alt Dr + 0 

/  : ~ 

\  : Majeur + \ 

|  : ~ 

(  : Majeur 9 

)  : Majeur 0 

{  : Alt gr 7 

}  : Alt gr } 

---------------------  

Clavier +: 

 «   = Ctl +W+-   

»    = Ctl +W - 

“    = Ctl + F2
