## 39\. Konjac

**Où en trouver:** Amazon
**Prix:** 4$ les 200g\*
**Avantages:** Effet coupe-faim 

Le Konjac est une plante qui est originaire d’Asie, elle est utilisée pour la cuisine mais aussi la médecine. Il est également connu pour être un coupe faim naturel ce qui devrait vous réjouir si vous avez décidé de commencer un régime minceur.

Les fibres présentes dans le Konjac permettent de lutter contre les problèmes de digestion comme la constipation. Sa fonction détoxifiante contribue à l’élimination des déchets et des toxines présents dans l’organisme d’où la raison pour laquelle le Konjac peut devenir votre allié le plus fidèle lors d’un régime.
