# Émotions

Quels sont les 7 émotions principales ?

Leur nombre varie selon les études, cependant on en retient généralement six :
**la joie
la surprise
la peur
la colère
le dégoût et la tristesse (une septième émotion, le mépris, est parfois ajoutée)**. Selon Paul Ekman, ces six émotions sont primaires de par leurs propriétés universelles [5].

****Comment** se **libérer** de **ses émotions négatives** ?**

1. Accepter **ses émotions négatives**. ...
2. Identifier le besoin derrière l'**émotion**. ...
3. Écrire **ses** pensées pour s'en **libérer**. ...
4. Exprimer **ses émotions négatives**. ...
5. Se préserver du négatif.
