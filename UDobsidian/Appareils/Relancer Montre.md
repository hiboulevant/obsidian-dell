## Ticwatch E3

Boot to recovery

I was struggling to find a procedure to reset my watch earlier this week because it wouldn't connect to my phone and settings was unusable. After hours of messing with it and getting stuck at the "NO COMMAND" screen, I gave up but decided to try again today and did this to get it to work:

1. Hold both side buttons
2. when it vibrates, let go and wait for boot
3. Use the bottom button to scroll to the recovery option and use the top button to select.
4. when the no command screen comes up, hold the top button and swipe up
5. use the bottom button to navigate the options and select using the top button.

Hope this will help anyone else who gets stuck in the same situation as I did
