# ScanSnap via le réseau

#ScanSnap #réseau #scan
Question à IA:

	Le scanSnap ne peut pas se connecter à ScanSnap via le réseau
Si votre ScanSnap ne peut pas se connecter via le réseau, voici quelques étapes à suivre pour résoudre le problème :

1. **Vérifiez la connexion réseau** :
   - Assurez-vous que le ScanSnap et l'ordinateur sont connectés au même réseau Wi-Fi.
   - Vérifiez que le réseau fonctionne correctement en testant la connexion avec d'autres appareils.

2. **Redémarrez les appareils** :
   - Redémarrez le ScanSnap ainsi que votre ordinateur pour réinitialiser les connexions réseau.

3. **Paramètres du ScanSnap** :
   - Ouvrez le logiciel ScanSnap Home sur votre ordinateur.
   - Accédez aux paramètres du ScanSnap pour vérifier que le mode de connexion est bien configuré sur "Réseau".

4. **Mise à jour du logiciel** :
   - Assurez-vous que le logiciel ScanSnap Home et le firmware du ScanSnap sont à jour. Les mises à jour peuvent corriger des problèmes de connectivité.

5. **Pare-feu et antivirus** :
   - Vérifiez que votre pare-feu ou logiciel antivirus ne bloque pas la connexion du ScanSnap. Vous devrez peut-être ajouter une exception pour le logiciel ScanSnap.

6. **Réinitialisation des paramètres réseau** :
   - Si le problème persiste, envisagez de réinitialiser les paramètres réseau du ScanSnap et de le reconfigurer.

Si après ces vérifications le problème persiste, consultez le manuel d'utilisation ou contactez le support technique de ScanSnap pour obtenir une assistance supplémentaire.
